# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting page:

https://github.com/alirashidnahal/expert-wage-calculator/security/advisories/new

Include the affected version, reproduction steps, impact, and any proposed mitigation. Do not include real user or case data. You should receive an initial response within seven days.

After a fix is available, a coordinated disclosure and security release will be prepared when appropriate.
