# Support

## Usage support

After the plugin is published, use its WordPress.org support forum for installation and usage questions.

## Bug reports

Use GitHub Issues for reproducible software defects. Include:

- WordPress, PHP, browser, and plugin versions.
- Active theme and relevant plugins.
- Calculator mode, tariff year, subject, and anonymized input values.
- Expected and actual behavior.
- Console errors or screenshots when relevant.

## Scope

Support does not provide legal advice or determine an expert's final wage. Calculation results remain estimates subject to the responsible authority.

Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
