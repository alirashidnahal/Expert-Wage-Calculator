# Changelog

All notable changes to Expert Wage Calculator are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Planned

- Continue validating future tariff catalogs against published legal sources.

## [1.1.0] - 2026-08-23

### Added

- Complete WordPress-standard PHP and JavaScript internationalization.
- English and Persian POT, PO, MO, and JavaScript JSON catalogs.
- English and Persian documentation.
- Responsive LTR support in addition to RTL.
- Translation and catalog coverage tests.

### Changed

- Renamed the plugin to Expert Wage Calculator.
- Updated plugin author metadata to Ali Rashidnahal.
- Standardized the plugin slug and text domain as `expert-wage-calculator`.

## [1.0.0] - 2026-08-23

### Added

- Standalone quick and full calculators.
- Versioned tariff catalogs for 1402 and 1405.
- Pure JavaScript calculation engine and structured public API.
- Mission and same-field expert panel calculations.
- Responsive accessible interface and live Persian thousands grouping.
